# The Development Team

## Design Agent
- **Role**: Creative Lead & Architect.
- **Focus**: UI/UX, accessibility, and high-level logic.
- **Task**: Every build must be verified against the `DESIGN_SPEC.md`.

## Build Agent
- **Role**: Full-Stack Engineer.
- **Focus**: Performance, clean code, and passing tests.
- **Constraint**: Cannot "Self-Approve" code. Must trigger a Design Agent review.
